# Product principles

1. **Quiet by default:** whitespace, clear hierarchy, a restrained palette.
2. **One small next step:** make logging easy and avoid unnecessary setup.
3. **Honest numbers:** source values where possible and label estimates.
4. **Kind language:** no food shaming or prescriptive “perfect body” framing.
5. **Accessible by default:** readable type, comfortable contrast, touch targets, English/Arabic and RTL.
6. **Purposeful motion:** animation should communicate a state change, not add noise.
7. **One design system:** central tokens and reusable interactions.
8. **Local-first foundation:** core manual logging should not require an account.
9. **Privacy by design:** no client-side secrets; be explicit before adding remote processing or sync.
