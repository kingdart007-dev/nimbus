# Roadmap

## Milestone 1 — Mobile foundation
- [x] App structure, Riverpod, GoRouter, Material 3 theme
- [x] English/Arabic localization and persisted theme/language preferences
- [x] Manual food, water, and activity interactions
- [x] CI formatting, analysis, and tests
- [ ] Add Android/iOS native runner directories and verify device builds
- [ ] Durable local storage and migrations

## Milestone 2 — Nutrition
- [ ] Fiber, sugar, sodium, meal types, favorites, history, and editable entries
- [ ] Food database/search with source and serving-size provenance
- [ ] Configurable nutrition targets and water history/reminders

## Milestone 3 — Capture and AI
- [ ] Barcode, nutrition-label, gallery/photo, and voice input
- [ ] AI estimates with confidence/source details and user confirmation
- [ ] Offline queues and resilient loading/error states

## Milestone 4 — Movement
- [ ] Workout descriptions, running, walking, and strength history
- [ ] Optional platform health integration for steps/activity
- [ ] Clearly labelled calorie-burn estimates with transparent assumptions

## Milestone 5 — Personalization and sync
- [ ] Goals that avoid one prescribed “perfect weight”
- [ ] Optional account and encrypted cloud sync
- [ ] Data export, privacy controls, and account deletion
- [ ] Evidence-based age-related insights only if a defensible method is selected

A feature is not done until it is accessible, localized, tested, and accurate about where its data came from.
